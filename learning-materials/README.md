## 記録のしかた

教材を使ったら、上の表へ公開URLと実際に取り組んだ範囲を追加します。授業を見終えたことと、自分で実装できたことを分けて記録します。

- HTML：見出し・画像・リンク・ボタンを使った小さなページを作る。
- CSS：余白・配置を調整し、PCとスマートフォンの幅で確認する。
- JavaScript：ボタン操作で表示や数値が変わる小さな機能を作る。

教材本文・動画・配布資料は転載せず、公開リンクと自分の言葉によるメモを残します。ログイン専用URLや認証情報は載せません。
