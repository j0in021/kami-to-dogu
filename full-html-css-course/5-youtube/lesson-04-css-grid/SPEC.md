## 理解確認

- grid-template-columnsの値の個数が列数になる。
- 1frは固定幅を除いた残り幅を受け取る。
- Gridは親へ指定し、直接の子がGrid itemになる。
- inline-block用のdisplay、vertical-align、固定カード幅、右marginが不要になる理由を説明できる。
