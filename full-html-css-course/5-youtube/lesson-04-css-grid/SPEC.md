## 目的

inline-blockの余分な空白と縦位置の問題を確認し、Gridで動画カードを同じ幅・同じ間隔の列へ並べる。練習用Gridから始め、最後にYouTubeクローンへ適用する。

## 実装仕様

| 対象 | 仕様 |
|---|---|
| Grid前の確認 | YouTube本体でinline-blockの空白、250pxでの折り返し、縦位置のずれを見る |
| 練習ファイル | `grid.html`を作り、動画の4例を順番に試す |
| 例1 | 100px・100pxの2列。2個目へ文章を足しても行の高さがそろうことを確認 |
| 例2 | 100px・100px・200pxの3列。4個目が次の行へ送られることを確認 |
| 例3 | 100px・1frの2列。右列が残り幅を使うことを確認 |
| 例4 | 100px・1fr・2frの3列。残り幅が1対2になることを確認 |
| 練習用の子要素 | 位置を見分けられるよう`div 1`以降の番号を表示する |
| 練習用の色 | 子要素を`lightblue`と`lightpink`で色分けする。画像は使用しない |

| 列幅練習 | px指定、`1fr`、`2fr`の比率を比較 |
| カード内部 | 投稿者画像50px、文章列は残り幅 |
| 動画一覧 | 3列の等幅Grid |
| 列間隔 | 16px |

## 本人が書く順序

1. YouTube本体で、300pxの中にinline-blockの50pxと250pxが空白のため収まらないこと、縦位置がずれることを確認する。
2. `grid.html`で100px・100pxの2列を作り、2個目へ文章を足しても縦がそろうことを確認する。
3. 100px・100px・200pxの3列と4個の子要素を作り、4個目の自動改行を確認する。
4. 100px・1frの2列で、`1fr`が残り幅を使うことを確認する。
5. 100px・1fr・2frの3列で、残り幅の1対2を確認する。
6. 動画カード内部を50pxと残り幅のGridへ変更する。
7. 動画一覧の親を3列Gridへ変更し、6件まで増やす。
8. 横16px・縦40pxの間隔を設定する。

## 見た目と合格条件

- [ ] 3列が等幅で、2行のカードが縦横にそろう。
- [ ] HTML中の空白を削除しなくても列間が崩れない。
- [ ] 文章が長くなっても投稿者画像列を押し広げない。
- [ ] `1fr`が残り幅を表すことを説明できる。
- [ ] Gridを親へ指定し、直接の子がGrid itemになることを説明できる。
- [ ] inline-blockからGridへ変えた理由を説明できる。
