### 固定配置と重なり順

`top`・`left`・`right`・`bottom`は、要素をどの端から何px離すかを決める。通常配置の`position: static`ではなく、`fixed`や`absolute`などの位置指定と組み合わせて使う。

#### ヘッダー

ヘッダーはブラウザー画面を基準に固定する。

| CSS | この画面での意味 |
|---|---|
| `position: fixed` | 通常の文書の流れから外し、スクロールしてもブラウザー画面に残す |
| `top: 0` | 画面上端との隙間を0にする |
| `left: 0` | 画面左端との隙間を0にする |
| `right: 0` | 画面右端との隙間を0にする。`left: 0`と併用すると左右いっぱいに広がる |
| `height: 56px` | ヘッダーの高さを固定する |
| `z-index: 100` | 他の配置要素より手前の層に置く。基本的に数値が大きい要素ほど手前に表示される |

```css
header {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  height: 56px;
  z-index: 100;
}
```

`fixed`にした要素は、後ろの要素が「そこにヘッダーがある」と認識して場所を空けてくれない。そのままでは本文の先頭がヘッダーの裏へ入るため、本文側に最低56px分の上余白を作る。上80pxから一覧を始める仕様は、ヘッダー56pxとその下の24pxの余白を合わせた値。

#### なぜ`z-index: 100`なのか

`100`はCSSで決められた必須値ではない。同じ重なりの仕組みの中では、他の要素より数値が大きければ手前になるため、ヘッダーだけなら`1`でも動く。

この課題では、後から追加する要素を整理しやすいよう、用途ごとに間隔を空けた番号を使う。

| 層 | 目安の値 | 用途 |
|---|---:|---|
| 通常の内容 | `auto`または`0` | 動画カードなど、重ねる必要のない内容 |
| カード内の表示 | `1` | サムネイル上の動画時間など |
| 左メニュー | `90` | スクロールする動画一覧より手前 |
| ヘッダー | `100` | ページ上部で常に最前面に見せる |

例えばヘッダーが`z-index: 1`でも、ほかの要素が`z-index: 2`なら、その要素がヘッダーの上に表示される。未指定の`auto`でも最初は正しく見える場合があるが、後から`position`と`z-index`を持つ要素を追加するとヘッダーが隠れる可能性がある。

`100`を採用した根拠は「100なら特別に強い」からではなく、通常内容の`0〜1`、左メニューの`90`、ヘッダーの`100`という役割別の順序を読みやすくし、途中へ別の層を追加できるようにするため。`9999`のような極端な値を増やすと管理しにくいため、この課題では使わない。

なお、`z-index`はページ全体で単純に数値だけを比べられない場合がある。親要素が別の重なりのグループを作ると、そのグループ同士の順序が先に決まる。この課題では、まずヘッダー・左メニュー・動画一覧を同じページ直下の層として扱い、上の値で管理する。

#### 左メニュー

左メニューも画面を基準に固定する。ヘッダーの下から始めるため`top: 56px`、左端へ付けるため`left: 0`、幅は72pxとする。必要なら`bottom: 0`で画面下端まで伸ばす。動画一覧側には左メニュー72pxと間隔24pxを合わせた96px分の左余白を確保する。

#### サムネイル上の動画時間

動画時間は画面ではなく、それぞれのサムネイルを基準に置く。サムネイルを包む要素へ`position: relative`、時間へ`position: absolute; right: 4px; bottom: 6px;`を指定する。

```text
position: fixed     → ブラウザー画面を基準に固定する
position: relative  → 子要素を置くための基準地点を作る
position: absolute  → 基準地点からtop/right/bottom/leftで配置する
z-index             → 要素が重なった時の前後関係を決める
```

`margin`や`padding`は周囲・内側の余白を作るもの。`top`などは配置の基準端からの距離を決めるもので、役割が異なる。

### 幅による変化

講座6:11付近を基準に、750px以下は2列、750pxより広く1000px未満は3列、1000px以上は4列。600・900・1200pxで確認する。

375pxのスマホ最適化は発展課題。取り組む時に1列化やヘッダー・メニューの省略を別途決める。教材の2列表示だけでスマホ対応完了とはしない。

## 動作と状態

- 検索欄には文字を入力できる。検索処理、音声入力、ログイン、通知取得、アップロードは今回の範囲外。学習用で検索機能がないことを説明する。
- サムネイルとタイトルは対応する動画URLへ同じタブで移動する。
- メニューはホバーで背景色が変わる。アイコンの説明はホバーで表示し、実務向けの追加確認ではフォーカス時にも表示する。
- ヘッダー・メニューはスクロールしても固定。時間ラベルは各画像の右下に重なる。
- タイトルが長くても隣のカードにはみ出さない。省略を採用する場合は全文を確認できる方法も決める。
- APIは使用しない。読み込み中・検索0件・通信失敗の状態は検索機能を追加する時に仕様化する。
- 素材は教材で案内されるものを使い、入手元を残す。一般的な再配布許可があるとは推測しない。
