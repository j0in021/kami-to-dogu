# 画面用アイコン

YouTubeクローン学習用に作成したオリジナルSVG素材です。既存サービスの公式ロゴやアイコンではありません。

| ファイル                     | 用途                     |
| ------------------------ | ---------------------- |
| `logo-videolab.svg`      | 学習用のVideoLabロゴ         |
| `icon-menu.svg`          | ハンバーガーメニュー             |
| `icon-search.svg`        | 検索                     |
| `icon-microphone.svg`    | 音声検索                   |
| `icon-create.svg`        | 動画作成                   |
| `icon-apps.svg`          | アプリ一覧                  |
| `icon-notifications.svg` | 通知                     |
| `avatar-profile.svg`     | プロフィール画像               |
| `icon-home.svg`          | Home                   |
| `icon-explore.svg`       | Explore                |
| `icon-subscriptions.svg` | Subscriptions          |
| `icon-originals.svg`     | Originals              |
| `icon-music.svg`         | YouTube Music相当の音楽メニュー |
| `icon-library.svg`       | Library                |

`youtube.html`からの相対パスは、例として `img/icons/icon-menu.svg` となります。

表示確認は[`preview.html`](preview.html)で行えます。
